# GitHub 系统截图采集

本目录用于真实浏览器运行截图，当前尚未采集。校园主题素材和设计参考图不能替代系统截图，不使用假数据拼图或 SSR 图片冒充实拍。

使用独立演示库，桌面浏览器建议1440×900、100%缩放；隐藏书签栏、开发工具和私有配置。等待图片加载及数字动画结束，避免出现通知浮层遮挡内容。使用浏览器或系统自带截图即可，无需安装工具。

| 文件名 | 路径 | 画面重点 |
| --- | --- | --- |
| `login.png` | `/login` | 完整校园 Hero、登录表单，无明文密码 |
| `dashboard.png` | `/admin/dashboard` | KPI、趋势、故障分析及校园任务分布 |
| `dispatch.png` | `/admin/dispatch?orderId=实际编号` | 当前工单、候选排名与四维解释，确认弹窗另可补拍 |
| `student.png` | `/student` | 当前进度、报修入口与最近工单 |
| `worker.png` | `/worker` | 待处理、维修中与返工任务 |

只使用公开演示账号，保留“演示”标识；不展示 JWT、数据库配置、真实姓名、电话或私人照片。PNG 保持原比例，建议不超过2MB；页面较长时可采集可见区域或浏览器完整页。

采集后人工确认清晰、无错误提示及布局错位，再在 README 添加相应图片。例如：

```markdown
![管理员校园维修运营中心](docs/screenshots/dashboard.png)
```

没有文件时不要添加会404的图片链接。真实截图补齐前，README只提供截图清单和采集入口，不宣称已完成视觉验收。
