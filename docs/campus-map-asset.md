# 校园示意地图

地图使用完全虚构的校园底图，不使用真实地址、在线地图服务或 GPS。后台楼栋和任务数据保持原样；本轮不写数据库。

- 底图：`frontend/src/assets/campus/campus-plan-v1.jpg`，1568 × 1003，约 535 KiB。
- 通过内置 imagegen 生成；底图不含文字，中文楼栋名称由前端 SVG 文本叠加，图标由路径绘制，避免生成文字失真及符号字体缺失。
- 楼栋名称及像素锚点统一定义在 `frontend/src/utils/campusMap.ts`，调整底图时应同步检查锚点。
- 图示包含教学楼 A/B 栋、学生宿舍 1/2/3 号楼、图书馆、第一食堂、运动场、维修服务站和南门。图示建筑不自动创建数据库记录。
- 工单优先按报修地点中的楼栋名称匹配；否则仅匹配距已知楼栋静态坐标 10 米以内的记录。维修员按静态坐标就近匹配 200 米内的已知楼栋，并明确标注非实时定位。经纬度不再显示。
- 未匹配项目仍可在地图页业务位置列表查看，不随意安放到示意建筑。图层切换使用完整楼栋上下文，不改变楼栋锚点。
- 保留缩放、平移、键盘选择和详情入口；同楼栋任务展开并保留连线。底图加载失败时保留标签和业务标记，并显示错误提示。

## 生成提示词

使用英文提示词生成无文字、俯视、浅色的虚构校园底图；随后按生成结果校准锚点。完整提示词见同目录 `campus-map-prompt.txt`。

## 验证边界

地图定向检查覆盖名称匹配、无坐标工单、未知地点不生成标记、静态人员匹配、密集标记边界、中文标签、标签避让及 SVG 渲染。生产构建包含 TypeScript 检查。未通过 GUI 自动化检查浏览器显示效果；窄屏实际阅读、拖拽、图片解码和动画仍以人工浏览器验收为准。
